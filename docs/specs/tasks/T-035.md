## Objetivo
Permitir que a banca veja, em minutos e sem UI, as garantias centrais funcionando.

## Entradas
`scripts/demo.sh` (rascunho), `03-design-contracts §5.1` e `§7`, `00-constitution §7` (sem UI).

## Saídas
- Profile `apps` no `deploy/docker-compose.yml` com os serviços `lancamentos` e `consolidado` (imagens geradas por `./mvnw spring-boot:build-image`; portas e gestão conforme `§5.1`; usuário não-root).
- `scripts/demo.sh` validado contra a stack real; `--kafka-down` opcional.
- Seção do README "Veja funcionando em 5 minutos" com os comandos.

## Critérios de aceite
- **AC-T035.1** Em stack limpa, `scripts/demo.sh` termina com exit 0, cada passo com asserção explícita.
- **AC-T035.2** Com `--kafka-down`, também termina com exit 0 (outbox acumula e drena; consolidado converge).
- **AC-T035.3** Se o script falhar no meio, o `trap` deixa Consolidado e Kafka em execução.
- **AC-T035.4** Cada execução usa comerciantes novos (nenhuma dependência de dados anteriores).

## Testes exigidos
Execução do script em CI (job manual) e verificação de sintaxe (`bash -n`, `shellcheck`).

## Não-objetivos
Interface gráfica, dados de demonstração persistentes, automação de deploy.
