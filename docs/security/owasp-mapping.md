# Mapeamento OWASP API Security Top 10 (2023)

Controle e teste de cada risco do `04 §2.6`. Cada teste está escrito como `classe#método` e existe no repositório; a revisão da T-034 confere um a um (AC-T034.7). Siglas: **L** = `lancamentos-service`, **C** = `consolidado-service`. Os testes de classes `*WebTest` rodam com a cadeia de segurança e os filtros reais (sem banco); os `*IT` usam Testcontainers.

## Fora do que os testes cobrem (decisões e limites)
- **Cabeçalho acima de 8 KiB (Q-080):** o Tomcat 11 não tem 431; ele responde 400 com uma página mínima do contêiner, sem *stack trace*. Essa resposta nasce antes da cadeia da aplicação, então não traz `problem+json` nem os cabeçalhos seguros. O 431 fica para a borda.
- **HSTS e TLS:** terminam na borda (gateway/ALB, ADR-010); localmente o tráfego é HTTP e nenhum HSTS é enviado.
- **Rate limit e WAF:** só desenho (ADR-010); a API não os implementa.
- **Pipeline:** CodeQL, Dependency-Check, Trivy e gitleaks (`04 §2.5`) rodam em `security.yml` e `ci.yml`; o resultado de cada run vive no GitHub, não neste documento. Supressões, quando houver, ficam em `docs/security/` com motivo, tarefa e validade.
